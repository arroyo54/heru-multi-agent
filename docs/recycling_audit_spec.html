1. Contexto original del cliente

Prompt original (sin editar)

"Mi novia trabaja en Walmart y es líder de los centros de reciclaje para más de 50 tiendas. En su día a día tiene que lidiar con los testigos de que se montaron los centros, es decir, las personas responsables de los centros, mandan fotos a un grupo de WhatsApp al abrir, al cerrar, y en el día con el centro limpio. También hay que tener testigos de la recolección de los centros mediante una foto del ticket de recolección. Mes a mes son miles de testigos a validar.

Objetivo: busco la manera de que pueda hacer eficiente este proceso, pero con la limitante que las personas que llevan los centros son analfabetas tecnológicos. Nada de apps, nada de procesos complicados.

Un bot en Telegram, se mandan las fotos del día al bot, de alguna manera esa información cae en una base de datos. Supabase, firebase, etc, y de ahí se almacena la información del día, el horario y se contrasta vs la meta data de la foto vs la localización pre-guardada del centro. Una vez que se tienen las fotos se genera una auditoría hecha por Claude. En el día tenemos 4 fotos: 2 de entrada y salida, 1 de limpieza y otra de bitácora y el comprobante es muy itinerante. Entonces la auditoría revisa esta data y da una aprobación al testigo o una referencia de algo no cuadra. Se detona una notificación y se revisa manualmente. Así en lugar de revisar una por una, se revisan las que la auditoría salgan con error."

Aclaraciones posteriores: Supabase como base de datos (no Google Sheets). Versión completa con dashboard y notificaciones. Script para cargar centros en cualquier momento.

2. Interpretación del problema

2.1 Dos tipos de usuario con necesidades opuestas

👷 Encargados de centro

  • Poca experiencia tecnológica
  • No pueden recordar comandos ni llenar formularios
  • El flujo completo del día: máximo 3 taps
  • Si falla una vez sin explicación clara, dejan de usarlo
  • El mayor riesgo no es la AI: es que el bot sea confuso

👩‍💼 Supervisora regional

  • Habilidades tecnológicas normales
  • Problema real: tiempo, no tecnología
  • Hoy revisa cientos de fotos manualmente al mes
  • Necesita demostrar cobertura a auditorías de Walmart
  • El valor: solo revisa las que fallan, no todas

2.2 El problema de fondo: trazabilidad legal

Los "testigos" son evidencia operativa. Walmart requiere demostrar que los centros operaron correctamente. Esto significa que los registros no se pueden perder, deben ser confiables (no fotos recicladas), y debe existir un trail de quién envió qué, cuándo y desde dónde.

2.3 Por qué Telegram y no WhatsApp

CriterioWhatsAppTelegram
Costo APIMeta Business API: tiene costo + aprobaciónGratis, sin aprobaciones
Botones interactivosLimitadosReplyKeyboard + InlineKeyboard nativos
Facilidad para usuarios no técnicosIgual de simpleIgual de simple
Control del botLimitadoTotal
Librería PythonComplejopython-telegram-bot (madura, async)

2.4 El insight central: revisión por excepción

En lugar de aprobar cada foto, el sistema aprueba automáticamente todo lo correcto y solo escala lo incorrecto. Claude Vision hace el trabajo pesado. La supervisora pasa de revisar 200 fotos/día a revisar 10–20 alertas. Las señales de alerta automáticas son: ubicación incorrecta, horario fuera de rango, foto duplicada exacta (mismo file_id de Telegram), contenido visual que no corresponde al tipo declarado.

-- ═══════════════════════════════════════════
-- VISTA: resumen_diario
-- Útil para el dashboard y reportes
-- ═══════════════════════════════════════════
CREATE OR REPLACE VIEW resumen_diario AS
SELECT
  c.id              AS centro_id,
  c.codigo,
  c.nombre,
  c.region,
  DATE(r.timestamp AT TIME ZONE 'America/Mexico_City') AS fecha,
  COUNT(r.id) FILTER (WHERE r.tipo = 'apertura')     AS fotos_apertura,
  COUNT(r.id) FILTER (WHERE r.tipo = 'limpieza')     AS fotos_limpieza,
  COUNT(r.id) FILTER (WHERE r.tipo = 'cierre')       AS fotos_cierre,
  COUNT(r.id) FILTER (WHERE r.tipo = 'comprobante')  AS fotos_comprobante,
  COUNT(r.id) FILTER (WHERE r.ai_estado = 'flagged') AS total_flags,
  COUNT(r.id) FILTER (WHERE r.ai_estado = 'aprobado') AS total_aprobados,
  BOOL_OR(r.tipo = 'apertura'    AND r.ai_estado != 'flagged') AS tiene_apertura,
  BOOL_OR(r.tipo = 'limpieza'    AND r.ai_estado != 'flagged') AS tiene_limpieza,
  BOOL_OR(r.tipo = 'cierre'      AND r.ai_estado != 'flagged') AS tiene_cierre,
  BOOL_OR(r.tipo = 'comprobante')                               AS tiene_comprobante
FROM centros c
LEFT JOIN registros r ON r.centro_id = c.id
WHERE c.activo = TRUE
GROUP BY c.id, c.codigo, c.nombre, c.region, DATE(r.timestamp AT TIME ZONE 'America/Mexico_City');

-- ═══════════════════════════════════════════
-- FUNCIÓN: detectar duplicado
-- Retorna TRUE si el file_id ya existe hoy para este centro
-- ═══════════════════════════════════════════
CREATE OR REPLACE FUNCTION es_foto_duplicada(
  p_centro_id UUID,
  p_file_id   TEXT
) RETURNS BOOLEAN LANGUAGE sql STABLE AS $$
  SELECT EXISTS (
    SELECT 1 FROM registros
    WHERE centro_id = p_centro_id
      AND foto_file_id = p_file_id
      AND DATE(timestamp AT TIME ZONE 'America/Mexico_City')
          = DATE(NOW() AT TIME ZONE 'America/Mexico_City')
  );
$$;

import math, uuid
from datetime import datetime
from zoneinfo import ZoneInfo

MEXICO_TZ = ZoneInfo("America/Mexico_City")

def haversine(lat1, lng1, lat2, lng2):
    R = 6_371_000
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dp = math.radians(lat2 - lat1)
    dl = math.radians(lng2 - lng1)
    a = math.sin(dp/2)**2 + math.cos(p1)*math.cos(p2)*math.sin(dl/2)**2
    return round(2 * R * math.asin(math.sqrt(a)))

def now_mx(): return datetime.now(MEXICO_TZ)
def now_iso(): return now_mx().isoformat(timespec="seconds")
def gen_id():  return str(uuid.uuid4())

def horario_valido(tipo, hora):
    rangos = {"apertura":(6,11), "limpieza":(7,19), "cierre":(17,23), "comprobante":(0,23)}
    lo, hi = rangos.get(tipo, (0,23))
    return lo <= hora <= hi

import os, json, base64, logging
import httpx, anthropic

log = logging.getLogger(__name__)
_client = None

DESCRIPCIONES = {
  "apertura":    "apertura del centro al inicio del día. Debe mostrar el área limpia, contenedores visibles y acceso despejado.",
  "limpieza":    "limpieza del centro durante el día. Área ordenada, sin residuos en el suelo, contenedores en su lugar.",
  "cierre":      "cierre del centro al final del día. Centro asegurado, área recogida, acceso cerrado.",
  "comprobante": "comprobante o ticket de recolección. Debe mostrar un documento físico con texto legible: fecha, cantidad, empresa recolectora.",
}

def _get():
    global _client
    if not _client:
        _client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])
    return _client

def audit_photo(photo_bytes: bytes, tipo: str, centro: str) -> dict:
    """Retorna {approved: bool, confidence: int, notes: str}"""
    b64 = base64.standard_b64encode(photo_bytes).decode()
    desc = DESCRIPCIONES.get(tipo, tipo)
    prompt = f"""Eres auditor de centros de reciclaje para Walmart México.
Esta foto fue enviada como evidencia de "{tipo}" para el centro "{centro}".
Se espera: {desc}

Evalúa si la foto es evidencia válida.
Responde SOLO con JSON válido sin texto extra:
{{"approved": true, "confidence": 85, "notes": "observación breve en español"}}

Reglas:
- approved=false si la imagen está muy oscura, borrosa, no muestra nada relevante, o no corresponde al tipo
- Para comprobante: approved=false si no hay texto legible
- En duda razonable: approved=true con confidence bajo (30–60)
- notes: máximo 2 oraciones, tono neutral y profesional"""
    try:
        msg = _get().messages.create(
            model="claude-sonnet-4-6",
            max_tokens=200,
            messages=[{"role":"user","content":[
                {"type":"image","source":{"type":"base64","media_type":"image/jpeg","data":b64}},
                {"type":"text","text":prompt}
            ]}]
        )
        text = msg.content[0].text.strip().lstrip("```json").lstrip("```").rstrip("```").strip()
        r = json.loads(text)
        return {"approved": bool(r.get("approved",False)),
                "confidence": int(r.get("confidence",50)),
                "notes": str(r.get("notes","Sin observaciones."))}
    except Exception as e:
        log.error(f"Error auditoría Claude: {e}")
        return {"approved": False, "confidence": 0, "notes": "Error técnico. Requiere revisión manual."}

async def download_photo(file_url: str) -> bytes:
    async with httpx.AsyncClient(timeout=30) as c:
        r = await c.get(file_url)
        r.raise_for_status()
        return r.content

import os, json, logging
from typing import Optional
import gspread
from google.oauth2.service_account import Credentials
from .utils import now_iso

log = logging.getLogger(__name__)
SCOPES = ["https://www.googleapis.com/auth/spreadsheets",
          "https://www.googleapis.com/auth/drive"]
_sheet = None

def _db():
    global _sheet
    if not _sheet:
        creds = Credentials.from_service_account_info(
            json.loads(os.environ["GOOGLE_SERVICE_ACCOUNT"]), scopes=SCOPES)
        _sheet = gspread.authorize(creds).open_by_key(os.environ["GOOGLE_SHEETS_ID"])
    return _sheet

# ── CENTROS ──────────────────────────────────────────────
def get_centro(codigo: str) -> Optional[dict]:
    rows = _db().worksheet("centros").get_all_records()
    for r in rows:
        if str(r.get("codigo","")).strip().upper() == codigo.strip().upper():
            if str(r.get("activo","TRUE")).upper() == "TRUE":
                return r
    return None

def list_centros() -> list:
    rows = _db().worksheet("centros").get_all_records()
    return [r for r in rows if str(r.get("activo","TRUE")).upper() == "TRUE"]

def add_centro(codigo, nombre, tienda_num, lat, lng, radio=300) -> bool:
    if get_centro(codigo): return False
    _db().worksheet("centros").append_row(
        [codigo.upper(), nombre, tienda_num, lat, lng, radio, "TRUE", now_iso()])
    return True

# ── TRABAJADORES ─────────────────────────────────────────
def get_worker(chat_id: int) -> Optional[dict]:
    rows = _db().worksheet("trabajadores").get_all_records()
    for r in rows:
        if str(r.get("telegram_chat_id","")) == str(chat_id):
            return r
    return None

def register_worker(chat_id, nombre, centro):
    if get_worker(chat_id): return
    _db().worksheet("trabajadores").append_row(
        [str(chat_id), nombre, centro["codigo"], centro["nombre"], now_iso()])

# ── REGISTROS ────────────────────────────────────────────
def is_duplicate(centro_codigo: str, file_id: str) -> bool:
    from .utils import now_mx
    today = now_mx().strftime("%Y-%m-%d")
    rows = _db().worksheet("registros").get_all_records()
    return any(
        str(r.get("codigo_centro","")).upper() == centro_codigo.upper()
        and str(r.get("foto_file_id","")) == file_id
        and str(r.get("timestamp",""))[:10] == today
        for r in rows

def db() -> Client:
    global _db

# ── CENTROS ──────────────────────────────────────────────
def get_centro(codigo: str) -> Optional[dict]:
    r = db().table("centros").select("*").eq("codigo", codigo.upper()).eq("activo", True).single().execute()
    return r.data if r.data else None

def list_centros() -> list:
    r = db().table("centros").select("*").eq("activo", True).order("nombre").execute()
    return r.data or []

def add_centro(codigo, nombre, tienda_num, lat, lng, radio=300) -> bool:
    try:
        db().table("centros").insert({
            "codigo": codigo.upper(), "nombre": nombre, "tienda_num": tienda_num,
            "lat": lat, "lng": lng, "radio_metros": radio
        }).execute()
        return True
    except Exception as e:
        log.error(f"add_centro error: {e}"); return False

# ── TRABAJADORES ─────────────────────────────────────────
def get_worker(chat_id: int) -> Optional[dict]:
    r = db().table("trabajadores").select("*, centros(*)").eq("telegram_chat_id", chat_id).eq("activo", True).execute()
    return r.data[0] if r.data else None

def register_worker(chat_id, nombre, username, centro_id):
    existing = db().table("trabajadores").select("id").eq("telegram_chat_id", chat_id).execute()
    if existing.data: return
    db().table("trabajadores").insert({
        "telegram_chat_id": chat_id, "nombre": nombre,
        "telegram_username": username, "centro_id": centro_id
    }).execute()

# ── REGISTROS ────────────────────────────────────────────
def is_duplicate(centro_id: str, file_id: str) -> bool:
    r = db().rpc("es_foto_duplicada", {"p_centro_id": centro_id, "p_file_id": file_id}).execute()
    return bool(r.data)

def save_record(rec: dict) -> dict:
    r = db().table("registros").insert(rec).execute()
    return r.data[0] if r.data else {}

async def upload_photo(photo_bytes: bytes, path: str) -> str:
    """Sube foto a Supabase Storage y retorna URL pública firmada."""
    db().storage.from_("fotos-centros").upload(
        path, photo_bytes, {"content-type": "image/jpeg", "upsert": "true"})
    url = db().storage.from_("fotos-centros").create_signed_url(path, 60*60*24*365)
    return url["signedURL"]

    r = (db().table("registros")
         .select("*, centros(nombre,codigo)")
         .eq("ai_estado","flagged")
         .eq("revisado_manual", False)
         .order("timestamp", desc=True)
         .limit(limit).execute())

def get_centros_sin_apertura() -> list:
    """Retorna centros activos que no han enviado apertura hoy."""
    from .utils import now_mx
    today = now_mx().strftime("%Y-%m-%d")
    todos = db().table("centros").select("id,codigo,nombre").eq("activo",True).execute().data or []

                    .eq("tipo","apertura")

                    .execute().data or [])

  const sorted = [...data].sort((a,b) => {

    if (a.total_flags > 0 && b.total_flags === 0) return -1;
    if (!a.tiene_apertura && b.tiene_apertura)     return -1;
    return a.nombre.localeCompare(b.nombre);
  });

  return (
    <div className="overflow-x-auto rounded-lg border">
      <table className="w-full text-sm">
        <thead className="bg-green-700 text-white">
          <tr>
            <th className="p-3 text-left">Centro</th>
            <th className="p-3">Apertura</th>
            <th className="p-3">Limpieza</th>
            <th className="p-3">Cierre</th>
            <th className="p-3">Comprobante</th>
            <th className="p-3">Flags</th>
          </tr>
        </thead>
        <tbody>
          {sorted.map(r => (
            <tr key={r.codigo} className="border-t hover:bg-green-50">
              <td className="p-3">
                <Link href={`/centro/${r.centro_id}`} className="font-medium text-green-800 hover:underline">
                  {r.nombre}
                </Link>
                <span className="ml-2 text-gray-400 text-xs">{r.codigo}</span>
              </td>
              {["tiene_apertura","tiene_limpieza","tiene_cierre","tiene_comprobante"].map(k => (
                <td key={k} className="p-3 text-center">
                  {r[k] ? "✅" : "❌"}
                </td>
              ))}
              <td className="p-3 text-center">
                {r.total_flags > 0
                  ? <Badge variant="destructive">{r.total_flags}</Badge>
                  : <span className="text-gray-300">—</span>}
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}

import os, logging
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron      import CronTrigger
import pytz

log = logging.getLogger(__name__)
MEXICO = pytz.timezone("America/Mexico_City")

def setup_scheduler(app):
    """
    Recibe la Application de python-telegram-bot y registra los jobs.
    Llamar desde bot.py después de build_app().
    """
    sched = AsyncIOScheduler(timezone=MEXICO)

    sched.add_job(
        lambda: app.create_task(alerta_apertura_faltante(app.bot)),
        CronTrigger(hour=11, minute=0, timezone=MEXICO),
        id="alerta_apertura", replace_existing=True
    )
    sched.add_job(
        lambda: app.create_task(alerta_cierre_faltante(app.bot)),
        CronTrigger(hour=21, minute=0, timezone=MEXICO),
        id="alerta_cierre", replace_existing=True
    )
    sched.add_job(
        lambda: app.create_task(resumen_diario(app.bot)),
        CronTrigger(hour=21, minute=30, timezone=MEXICO),
        id="resumen_diario", replace_existing=True
    )
    sched.start()
    log.info("Scheduler iniciado.")
    return sched

async def _get_admins():
    return [int(x) for x in os.environ.get("ADMIN_CHAT_IDS","").split(",") if x.strip().isdigit()]

async def alerta_apertura_faltante(bot):
    from .database_supabase import get_centros_sin_apertura
    sin_ap = get_centros_sin_apertura()
    if not sin_ap: return
    lineas = "\n".join(f"• `{c['codigo']}` {c['nombre']}" for c in sin_ap[:15])
    msg = f"⏰ *11:00am — Centros sin apertura ({len(sin_ap)}):*\n\n{lineas}"
    for aid in await _get_admins():
        try: await bot.send_message(aid, msg, parse_mode="Markdown")
        except Exception as e: log.error(e)

async def alerta_cierre_faltante(bot):
    from .database_supabase import db
    from .utils import now_mx
    today = now_mx().strftime("%Y-%m-%d")
    todos = db().table("centros").select("id,codigo,nombre").eq("activo",True).execute().data or []
    con_cierre = {r["centro_id"] for r in
        db().table("registros").select("centro_id")
            .eq("tipo","cierre").gte("timestamp",f"{today}T00:00:00-06:00")
            .execute().data or []}
    sin_ci = [c for c in todos if c["id"] not in con_cierre]
    if not sin_ci: return
    lineas = "\n".join(f"• `{c['codigo']}` {c['nombre']}" for c in sin_ci[:15])
    msg = f"🔒 *9:00pm — Centros sin cierre ({len(sin_ci)}):*\n\n{lineas}"
    for aid in await _get_admins():
        try: await bot.send_message(aid, msg, parse_mode="Markdown")
        except Exception as e: log.error(e)

async def resumen_diario(bot):
    from .database_supabase import get_today_summary, list_centros
    resumen = get_today_summary()
    cs = list_centros()
    total = len(cs)
    if not resumen: return
    completos  = sum(1 for r in resumen if r.get("tiene_apertura") and r.get("tiene_cierre"))
    flags      = sum(r.get("total_flags",0) for r in resumen)
    aprobados  = sum(r.get("total_aprobados",0) for r in resumen)
    from .utils import now_mx
    hoy = now_mx().strftime("%d/%m/%Y")
    msg = (f"📊 *Resumen del {hoy}*\n\n"
           f"Centros completos: *{completos}/{total}*\n"
           f"Fotos aprobadas: *{aprobados}*\n"
           f"Flags pendientes: *{flags}*\n\n"
           f"{'✅ Excelente día.' if flags == 0 else '⚠️ Hay registros pendientes de revisión en /flags'}")
    for aid in await _get_admins():
        try: await bot.send_message(aid, msg, parse_mode="Markdown")
        except Exception as e: log.error(e)
    # Enviar resumen por email también
    if os.environ.get("RESEND_API_KEY") and os.environ.get("SUPERVISOR_EMAIL"):
        await send_daily_email(hoy, completos, total, flags)

"""
Uso:
    python scripts/load_centers.py centros.csv
    python scripts/load_centers.py centros.csv --dry-run  (solo muestra, no guarda)

Carga masiva de centros desde CSV a Supabase o Google Sheets
según las variables de entorno disponibles.
"""
import sys, os, csv
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent))
from dotenv import load_dotenv; load_dotenv()

DRY = "--dry-run" in sys.argv

def load(filepath):
    added = skipped = 0; errors = []
    # Detectar backend
    if os.environ.get("SUPABASE_URL"):
        from agents.recycling_audit.database_supabase import add_centro, get_centro
    else:
        from agents.recycling_audit.database import add_centro, get_centro

    with open(filepath, newline="", encoding="utf-8") as f:
        for i, row in enumerate(csv.DictReader(f), 2):
            try:
                code = row["codigo"].strip()
                name = row["nombre"].strip()
                lat  = float(row["lat"])
                lng  = float(row["lng"])
                if not code or not name or not lat or not lng:
                    errors.append(f"Fila {i}: datos incompletos"); continue
                radio  = int(row.get("radio_metros",300) or 300)
                tienda = row.get("tienda_num","").strip()
                if DRY:
                    print(f"[DRY] {code} — {name} ({lat},{lng})"); added += 1; continue
                if add_centro(code, name, tienda, lat, lng, radio):
                    print(f"✅ {code} — {name}"); added += 1
                else:
                    print(f"⏭  Ya existe: {code}"); skipped += 1
            except Exception as e:
                errors.append(f"Fila {i}: {e}")
    print(f"\n{'─'*40}")
    print(f"{'[DRY RUN] ' if DRY else ''}Agregados: {added} | Ya existían: {skipped}")
    if errors:
        print(f"Errores ({len(errors)}):"); [print(f"  • {e}") for e in errors]

if __name__ == "__main__":
    f = next((a for a in sys.argv[1:] if not a.startswith("--")), None)
    if not f: print("Uso: python scripts/load_centers.py archivo.csv"); sys.exit(1)
    if not os.path.exists(f): print(f"Archivo no encontrado: {f}"); sys.exit(1)
    print(f"Cargando desde: {f} {'(DRY RUN)' if DRY else ''}\n")
    load(f)

13. Checklist de pruebas

Bot — Flujo de registro

  • ☐ Encargado nuevo escribe código válido → queda registrado, ve el menú
  • ☐ Encargado escribe código inválido → mensaje de error claro
  • ☐ Encargado ya registrado hace /start → va directo al menú
  • ☐ Encargado inactivo (activo=false) → se le pide registrarse de nuevo

Bot — Flujo de foto

  • ☐ Apertura: botón → ubicación → foto → ✅ en Supabase con ai_estado correcto
  • ☐ Limpieza: mismo flujo
  • ☐ Cierre: mismo flujo
  • ☐ Comprobante: puede saltar ubicación → foto guardada
  • ☐ Foto enviada sin elegir tipo primero → bot pide elegir tipo
  • ☐ Foto enviada sin ubicación en flujo que la requiere → bot pide ubicación

Bot — Detección de anomalías

  • ☐ Misma foto enviada 2 veces el mismo día → segunda marcada como duplicado y flagged
  • ☐ Foto enviada desde ubicación falsa (>300m) → ubicacion_ok=FALSE y flagged
  • ☐ Supervisora recibe notificación con foto reenviada y motivos del flag
  • ☐ Foto de apertura enviada a las 3pm → horario_ok=FALSE (no bloquea, solo registra)

Bot — Comandos admin

  • ☐ /centros → lista de centros activos con códigos
  • ☐ /addcentro → flujo guiado completo, centro aparece en BD
  • ☐ /reporte → resumen del día con emojis ✅/❌ por tipo
  • ☐ /flags → lista de registros pendientes de revisión
  • ☐ Trabajador intenta usar comandos admin → bot no responde (silencio seguro)

Scheduler — Notificaciones programadas

  • ☐ 11am: alerta llega con lista de centros sin apertura
  • ☐ 9pm: alerta llega con lista de centros sin cierre
  • ☐ 9:30pm: resumen diario completo llega por Telegram
  • ☐ Si no hay alertas, no se envía mensaje (silencio correcto)

Dashboard

  • ☐ Página principal muestra KPIs del día actual
  • ☐ Tabla de centros ordenada: primero con flags, luego incompletos
  • ☐ /flags muestra fotos con motivos de rechazo
  • ☐ Clic en centro muestra historial de envíos

Script de carga masiva

  • ☐ --dry-run lista centros sin guardar nada
  • ☐ Carga correcta de 50+ centros desde CSV
  • ☐ Códigos duplicados se omiten sin error
  • ☐ Filas con datos incompletos reportan error con número de fila

14. Evolución futura

Lo siguiente NO forma parte del alcance actual pero el diseño lo permite sin reescritura:
  • Reportes PDF mensuales: WeasyPrint o Puppeteer generan un PDF desde HTML con las estadísticas del mes. Se envía por email el primer día de cada mes.
  • Multi-región con permisos: Supabase Auth + RLS para que cada supervisora regional solo vea sus centros. Ya hay columna region en la tabla centros.
  • Validación visual avanzada: guardar hashes perceptuales (imagehash) de fotos aprobadas y comparar contra nuevas entregas. Detecta fotos casi-idénticas aunque tengan file_id diferente.
  • App móvil (React Native + Expo): si en el futuro los encargados son más sofisticados. La API de Supabase ya está lista.
  • Integración con Walmart: exportar reportes de cumplimiento en el formato que pide Walmart internamente. Solo se necesita un script de exportación.
  • WhatsApp como canal alternativo: migrar el bot a WhatsApp Business API cuando el presupuesto lo permita. Toda la lógica de auditoría es independiente del canal.
